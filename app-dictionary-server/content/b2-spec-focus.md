# B2 course: the one rule that matters most

This is the B2 (upper-intermediate, CEFR) level of an English course for UZBEK-speaking learners.
The user's request: build it around the places where learners get CONFUSED and MAKE MANY MISTAKES.
So every exercise must test a real, frequent error, never a trivial fact.

## What "tricky" means here (use these as your source of material)

1. Contrast pairs that Uzbek speakers mix up: present perfect vs past simple (Uzbek has no equivalent), simple vs continuous,
   past simple vs past perfect, used to / would / be used to, will vs going to, must vs have to, mustn't vs don't have to,
   should have vs must have vs could have, gerund vs infinitive after the same verb (stop/remember/forget/try/regret/go on/mean),
   a/the/zero article, much/many/few/little/a few/a little, so/such, too/enough, since/for/ago, during/while, by/until, in time/on time.
2. Uzbek-influence errors: missing articles, wrong prepositions (depend of, married with, discuss about, listen the music, arrive to),
   word order in questions and reported questions, uncountable nouns used as countable (advices, informations, furnitures, news are),
   -ing/to-infinitive confusion, double negatives, wrong tense after when/if/as soon as/by the time.
3. Look-alike or sound-alike words: say/tell, make/do, lend/borrow, bring/take, hear/listen, look/see/watch, rise/raise, lie/lay,
   economic/economical, sensible/sensitive, actually/currently, eventually/possibly, lecture/reading, fun/funny, historic/historical,
   affect/effect, advice/advise, beside/besides, hardly/hard, late/lately, quite/quiet, principal/principle, etc.
4. Phrasal verbs whose particle changes the meaning, separable vs inseparable (look after, put off, give up, turn down, get over,
   put up with, come up with, run out of, look forward to).

## Rules for wrong options (distractors)

- Wrong options must be the exact mistakes learners really make (from the lists above), not random or silly words.
- Exactly one option must be correct in context. Add a time word or context clue (since 2019, yesterday, already, by the time...)
  whenever the choice depends on it, so there is no second valid answer.
- Never test a spelling only; test grammar, word choice or meaning.

## Explanations and style

- Uzbek explanations/rules/tips use Latin script with the apostrophe ' (o', g', ').
- English must be natural, correct, B2-level (richer vocabulary and longer structures than B1), plain apostrophes only.
- Double-check every item: if in doubt whether two options are both correct, rewrite the sentence.
- Do not copy lines from any other file; write fresh, varied content (different names, places, jobs, situations).
