# Format
#   "# <Murphy topic no> | <title> | <short rule in Uzbek> | <tip shown with the answer>"
#   then one line per sentence:  Sentence with [answer] | wrong1, wrong2 ~ hint
# Every sentence becomes a TEST item (needs the wrong options), a FILL item (the hint is shown in brackets)
# and, when it is short, an ORDER item. If a line holds a question and an answer ("Is it? Yes, it [is]."),
# the ORDER item is built from the answer part.
# Topic numbers follow the "Qizil Murphy" topic list (Essential Grammar in Use).
